# Problem Solving

A comprehensive collection of algorithm and data structure solutions from various sources, including HackerRank challenges and problems from the "Cracking the Coding Interview" book.

## 📚 Overview

This repository contains solutions to coding challenges organized into three main categories:
- **HackerRank Problems**: Algorithm challenges from HackerRank platform
- **Cracking the Coding Interview**: Classic problems from the CTCI book
- **SQL Challenges**: Database query problems

All algorithmic problems are implemented in **C#**, while SQL problems use **MySQL** and **T-SQL**.

## 📂 Repository Structure

### HackerRank (~64 Problems)
Solutions to various HackerRank challenges covering:
- Algorithm challenges (arrays, strings, sorting, searching, etc.)
- 30 Days of Code series
- 10 Days of Statistics series
- Problem-solving exercises

### Cracking The Coding Interview (~33 Problems)
Organized by topic from the CTCI book:
- **Arrays and Strings**: String manipulation, array operations
- **Linked Lists**: Single/double linked list operations
- **Trees and Graphs**: Tree traversals, graph algorithms
- **Sorting and Searching**: Various sorting algorithms, binary search
- **Recursion and Dynamic Programming**: Recursive solutions, DP optimization

### SQL (~39 Problems)
Database query challenges organized by difficulty:
- **Easy** (29 problems): Basic queries, aggregations, filtering
- **Medium** (10 problems): Complex joins, subqueries, advanced operations

## 🛠️ Technologies

- **Language**: C# (.NET Core / .NET Framework)
- **Databases**: MySQL, T-SQL (SQL Server)
